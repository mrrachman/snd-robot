🎯

Entry hanya di zona valid

Zona supply & demand dipindai otomatis: Rally-Base-Rally untuk beli, Drop-Base-Drop untuk jual. Zona basi & zona bentrok otomatis diabaikan.

🧭

Filter arah EMA200

BUY hanya saat harga di atas EMA200, SELL hanya di bawahnya. Menolak melawan arus — zone-trend dua paket satu paket.

🛟

Lot penyelamat pintar

Kalau harga menjauh jarak tertentu, robot kirim lot 3× untuk turunkan rata-rata. Maksimal 2× saja — tidak ada martingale tanpa rem.

✂️

Cutloss EMA tiga mode

Bisa di-set cutloss saat candle tembus EMA, saat harga menyentuh, atau saat harga menjauh dari EMA. Terakhir ini favorit: tidak nunggu candle tutup.

📊

TP basket rata-rata

Setiap ada posisi baru, semua target profit digeser ke rata-rata tertimbang lot. Basket selesai lebih cepat, dana tidak lama menganggur.

🔒

Lisensi per akun

Robot mengikat nomor akun MT5-mu. Bocor file ke teman = tidak jalan. Lisensi dicabut = robot berhenti, bukan cuma di awal.
